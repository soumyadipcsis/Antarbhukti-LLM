You are an expert in control software design using IEC 61131-3 Sequential Function Charts (SFCs).

[The Domain]
Sequential Function Charts (SFCs) are graphical programming languages used in PLCs. An SFC consists of:
- Steps: States in the control process, each with associated actions/functions.
- Transitions: Conditions that cause movement from one step to another.
- Guards: Boolean conditions that enable transitions.
- Variables: Input/output and internal variables used in the control logic.

[The Task]
Your task is to take an initial SFC as input and generate a precise "When/Action" logic prompt, followed by the upgraded SFC that implements those exact rules to improve system [TARGET_DOMAIN: Safety OR Reliability].

[Input SFC]
<SFC_initial>
{INSERT_JSON_HERE}
</SFC_initial>

[Upgrade Library]
Select EXACTLY ONE or TWO distinct rules from the appropriate category below. DO NOT apply more than two rules. 

If [TARGET_DOMAIN] is Reliability:
1. Input Validation: (When: Input out of range -> Action: ValidateInput step -> ValidationError state).
2. Execution Bounds: (When: Loop exceeds max iterations -> Action: Track count -> SafeAbort state).
3. Intermediate Logging: (When: Critical transition occurs -> Action: Insert Log step to record state).
4. Watchdog Monitoring: (When: Variable becomes undefined -> Action: WatchdogCheck -> WatchdogError).

If [TARGET_DOMAIN] is Safety:
1. Safety Input Check: (When: Safety-critical input missing/OOB -> Action: SafetyCheckInput -> SafetyError halt).
2. Timeout Safe Stop: (When: Actuation exceeds safe time limit -> Action: Timeout check -> TimeoutSafeStop).
3. Safe State Logging: (When: After safety-relevant cycle -> Action: SafetyLog step recording margins).
