# ST → SFC Benchmark Dataset

This dataset contains Structured Text (ST) programs designed for
evaluating automatic translation into Sequential Function Chart (SFC).

## Contents

-   Core IEC timers
-   Memory elements
-   Sequencing control problems
-   Industrial process models
-   Manufacturing cell sequences

Each file contains explicit state-machine logic using CASE state OF
patterns.

## Usage

python ST2SFC.py \<file.st\>

## Purpose

-   Parser testing
-   Transition extraction validation
-   Formal verification benchmarking
